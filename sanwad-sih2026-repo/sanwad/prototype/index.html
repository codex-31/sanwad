Problem-statement requirements → where they are

10 Indian languages — language screen On-device STT + TTS, offline — status bar ⓘ sheet Pause detection → sentence forming — hold-to-talk flow Wi-Fi / Bluetooth streaming, minimal latency — packet log + link bar TTS plays received text as voice note — Phone B playback Alerts: max volume, non-interruptible — ⚠ toggle on sender Two-phone walkie-talkie, push-to-talk — this live loop Off = normal phone — “Phone” mode toggle

Prototype note: STT/TTS are simulated in-browser (live Web Speech APIs are used automatically where the browser supports them); the phone-to-phone transport is simulated over an in-page bus with realistic ~0.5 s latency. All model names, footprints and latency figures on the ⓘ sheet reflect the intended on-device architecture (IndicConformer int8 STT · espeak-ng / Piper TTS · 2 GB RAM target).
